# Digital vs Traditional Learning

This project is a static information website exploring the differences between digital learning and traditional classroom learning, with a focus on access, engagement, motivation, retention, and fairness for learners in South Africa.

## Overview

The site presents a research-based comparison of the two learning approaches and highlights the benefits and limitations of each. It includes sections on:

- access and affordability
- traditional learning
- digital learning
- motivation and engagement
- safety and responsible online use
- conclusion and recommendations
